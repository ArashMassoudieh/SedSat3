◆ DefaultRandomSeed

constexpr std::uint64_t DefaultRandomSeed = 20261016
constexpr

The stream for code outside the MCMC that needs random numbers.

One per thread, so parallel code never shares a generator. Every thread's stream starts from the same fixed seed (DefaultRandomSeed), so a run is repeatable; code whose result must not depend on what ran before it (the Levenberg-Marquardt starting point, Error Analysis) uses its own RandomStream instead. Because every thread's stream starts from the same seed, parallel code must not draw from it: give each chain or task its own RandomStream(seed, index), as the MCMC does.
