Detailed Description

The one place where data values entering SedSAT3 are checked.

Every concentration, ratio and option read from an Excel file, a project file, the command line or the element table goes through these functions, so the rest of the program can rely on every stored value being a finite number. A value that fails is not stored: the import or load stops and reports where the value is (sheet, row and column, or group, sample and constituent) and why it was refused. This is the same treatment empty and non-numeric Excel cells have always had; SedSAT3 has no missing-data value.

Accepted: an optional sign, digits with '.' as the decimal separator, and an optional exponent, with surrounding spaces ignored ("12", "-0.5", "1.5e-3"). Refused: empty text; NaN, Inf and Infinity in any case; numbers too large for a double; anything else, including "1,5" (a decimal comma) and "1,234" (a thousands separator), which are reported as such.
