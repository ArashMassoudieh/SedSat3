Detailed Description

Holds a progress reporter for the duration of one analysis.

Obtains a reporter from the host on construction and returns it on destruction, so that an analysis leaving by any of its return paths still releases it. It converts to ProgressReporter* and forwards operator->, so it can be used wherever a reporter pointer was used before.
